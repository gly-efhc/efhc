# backend/requirements.txt
# =============================================================================
# Назначение кода:
# Список зависимостей EFHC Bot (API + интеграции + бот + миграции), согласованный
# с каноном (Pydantic v2, FastAPI v0.115+, SQLAlchemy v2). Файл ориентирован на
# деплой в окружение с PostgreSQL/Neon и асинхронным стэком.
#
# Канон/инварианты:
# • Только Pydantic v2 (не смешивать с v1-пакетами).
# • SQLAlchemy 2.x + asyncpg для async, Alembic для миграций (sync URL).
# • Aiogram 3.x как базовый Telegram-бот фреймворк.
# • httpx как универсальный HTTP-клиент для TON/GetGems (таймауты/HTTP2).
#
# Примечания:
# • Для Alembic используем sync-драйвер (psycopg2-binary), а для приложения — asyncpg.
# • uvloop ставится только не на Windows.
# • Версии закреплены «штангой» (>=,<) для предсказуемости, но допускают минорные апдейты.
# • Файл покрывает runtime, migrations и минимальный CI/test helper layer текущего HEAD.
# =============================================================================
