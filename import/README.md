# Импорт EFHC

`main` — единая интегрированная база исходного кода. ZIP не заменяет исходники автоматически. Архивы сравниваются в отдельной рабочей копии, изменения переносятся предметным diff через обязательные проверки и интеграцию в актуальный `main`.

Полный архив при необходимости валидируется без записи через Full ZIP validation или локально командой `python3 .github/scripts/efhc_import_full.py <ZIP> <SHA-256> --root <отдельная рабочая копия>`. Приватный исходник, секреты и архивы в публичный репозиторий не загружать. Pages собирает текущий Git commit, не выполняет импорт и не изменяет Git.
