# Импорт EFHC

- **Только фронтенд.** Загрузите один React ZIP в `import/`. Workflow React import проверяет файлы и переносит только штатный фронтенд. Pages сверяет именно React ZIP с записью в `site/RELEASE.json`.
- **Полный исходный код.** `EFHC_FULL_IMPORT.zip` содержит и сервер. Не загружайте непубличный исходник в открытый GitHub: даже отдельная ветка публична. Если файл уже есть в `import/`, отдельный workflow Full ZIP validation сверяет архив только на чтение, без распаковки в Git, записи в main, загрузки артефактов или деплоя.
- Для полного импорта в закрытую рабочую копию используйте `python3 .github/scripts/efhc_import_full.py <ZIP> <SHA-256> --root <отдельная рабочая копия>`. Повторите с `--apply` только после успешной проверки. Скрипт не заменяет отличающиеся файлы.
- Pages не запускает Python-сервер. После полного импорта проверяйте сборку и старт на изолированном Genesis TEST отдельно. Не используйте production-БД или реальные платежи.
